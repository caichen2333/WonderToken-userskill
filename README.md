# WonderToken 玩途 Skill

WonderToken 是面向 Codex 的旅行宠物 Skill。当前公开版本仅承诺支持 Codex。

## 使用范围

- Skill 代码允许非商业使用、修改和再发布，适用 PolyForm Noncommercial 1.0.0。
- 文档和宠物图片允许署名后的非商业修改和再发布，适用 CC BY-NC-SA 4.0。
- 修改版不得声称是 WonderToken 官方版本。
- 商业使用请联系：caichen0723@163.com。

## 服务连接

正式 MCP 地址将在公网部署完成后写入发行配置。远程服务必须使用有效的 HTTPS 地址；本地开发可以使用 localhost。
